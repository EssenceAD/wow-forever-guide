와우 채팅 실시간 번역 창 — 사용법
====================================

■ 처음 한 번
1. 이 폴더를 원하는 곳에 둡니다 (예: 바탕화면).
2. "번역창 실행.bat" 을 더블클릭합니다.
   - 처음에는 Python과 필요한 패키지를 자동으로 설치합니다 (몇 분, 인터넷 필요).
   - Windows가 "PC 보호" 창을 띄우면 [추가 정보] → [실행] 을 누르세요.
3. Claude API 키를 묻는 창이 뜨면 붙여 넣습니다 (sk-ant- 로 시작).
   키는 이 폴더의 .env 파일에만 저장됩니다. 남에게 폴더를 줄 때는 .env 를 지우세요.

■ 게임에 접속할 때마다 (중요!)
1. 와우 채팅창에 /chatlog 를 입력합니다.
   → "채팅 기록 저장 시작"(Chat being logged) 같은 메시지가 나오면 성공.
   → 한 번 더 입력하면 꺼지니 한 번만 입력하세요.
2. 번역 창의 맨 아래 상태줄에 "_forever_ 감시 중" 같은 글자가 보이면 정상입니다.
   "채팅 기록 꺼짐 → 게임에서 /chatlog" 가 보이면 1번을 다시 하세요.
3. 게임을 재접속해도 번역 창은 켜 둔 채로 두면 됩니다. 자동으로 다시 따라갑니다.

■ 화면 보는 법
   21:15 · [파티] 小明        ← 시각 · 채널 · 이름
   缺一個補，來的密我         ← 원문 (작은 회색 글씨)
   힐러 한 명 구해요, 올 사람 귓말  ← 번역 (큰 글씨)
 - 초록색 번역은 88, 3Q, ty, gg 같은 약어를 사전으로 바로 푼 것 (무료).
 - 한국어 채팅, 숫자·기호만 있는 채팅, 시스템 메시지(아이템 획득, 경험치 등)는 번역하지 않습니다.
 - 위쪽 체크박스로 보고 싶은 채널만 고르세요.
   기본: 파티·귓속말·길드·일반 대화만 켜짐 (공개·거래는 도배가 많아 꺼 둠).
   꺼 둔 채널은 번역도 하지 않아 사용량이 줄어듭니다.
 - 투명도 막대, "항상 위" 체크, 창 크기·위치는 다음 실행 때도 기억합니다.

■ 답장하기
1. 아래 입력칸에 한국어로 씁니다. 예) 부활 없어서 뛰어오셔야 해요
2. 옆에서 "대만어 (번체)" 또는 "영어" 를 고르고 Enter (또는 [번역]).
3. 번역문이 자동으로 클립보드에 복사됩니다.
4. 게임 채팅창을 열고 Ctrl+V → Enter 는 직접 누르세요.
 - 와우 채팅 한 줄은 255바이트까지입니다 (중국어는 약 85글자).
   넘으면 빨간 경고가 뜨니 문장을 나눠서 보내세요.

■ 사용량
 - 하단 상태줄에 "오늘 번역 N/1000회" 가 보입니다. 하루 1,000회가 넘으면 번역을 멈추고 원문만 보여 줍니다.
 - 같은 문장(거래 채널 도배 등)은 저장해 둔 번역을 다시 쓰므로 횟수가 늘지 않습니다.
 - 한도·모델은 config.json 에서 바꿀 수 있습니다 (메모장으로 열기).
     "daily_limit": 1000          ← 하루 최대 번역 횟수
     "model": "claude-haiku-4-5"  ← 번역에 쓰는 Claude 모델

■ 상태줄의 "기록 지연"
 - 채팅이 게임에 뜬 시각과 파일에 기록된 시각의 차이입니다.
 - ⚠ 표시와 함께 3초보다 크게 나오면 게임이 로그를 늦게 저장하는 것입니다.
   이 경우 번역이 늦게 뜨는 건 프로그램 문제가 아니니 개발자에게 이 숫자를 알려 주세요.

■ 문제가 생기면
 - 와우 폴더를 못 찾는다고 나오면: ⚙ 설정 → "로그 파일 위치 직접 지정" →
   와우 설치 폴더 안의 _forever_ (또는 비슷한 이름) → Logs 폴더를 고르세요.
   Logs 폴더가 없으면 게임에서 /chatlog 를 먼저 한 번 입력하세요.
 - 채팅이 전혀 안 뜨면: ⚙ 설정 → "진단 정보" 를 여세요.
   게임에서 채팅을 몇 줄 친 뒤 [새로고침] → 감시 중인 파일 크기가 늘어나는지 봅니다.
   [전체 복사] 로 복사해서 개발자에게 보내 주면 원인을 바로 찾을 수 있습니다.
 - 인식 못한 줄은 data\인식못한_줄.txt 에 쌓입니다.
   채팅 줄이 여기 쌓여 있다면 형식이 달라서 못 읽은 것입니다. 이 파일을 개발자에게 보내 주세요.
 - API 키를 바꾸려면: ⚙ 설정 → API 키 변경.
 - 오류 기록: data\error.log
 - 설치가 꼬이면 .venv 폴더를 지우고 "번역창 실행.bat" 을 다시 실행하세요.

■ 블리자드 약관 관련
 이 프로그램은 와우가 직접 만드는 채팅 기록 파일(WoWChatLog.txt)을 읽기만 합니다.
 게임 메모리를 읽거나, 키보드·마우스를 대신 누르거나, 채팅을 자동으로 보내지 않습니다.
 답장 붙여넣기와 전송은 항상 직접 하세요.
